# SpecForge FSI v1.1.0 freeze approvals

Status: pending independent approval

This version changes the symmetric per-run execution timeout from 5,400 seconds
(90 minutes) to 7,200 seconds (120 minutes). The original
`specforge-fsi-v1.0.0` evidence and its timeout remain immutable.

It also changes presentation and report contract policy: categorized token
consumption is the non-monetary cost proxy, while productive and elapsed time
remain separate delivery-efficiency measures. Monetary pricing remains optional.

Any v1.1.0 rerun must execute the complete randomized 24-run matrix. Previously
timed-out MAI Code 1.1 Flash runs must not be rerun in isolation.
